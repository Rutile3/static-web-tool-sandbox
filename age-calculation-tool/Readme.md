# 年齢計算ツール

生年月日と基準日を入力して、基準日時点の年齢情報を確認できるWebツールです。
**満年齢、数え年、生後日数、次の誕生日までの日数** をブラウザ上で計算します。

> このツールはブラウザ上で動作します。  
> 入力された生年月日や基準日はサーバーへ送信せず、保存もしません。

---

## 主な機能

- 生年月日と基準日をもとにした年齢計算
- 満年齢、数え年、生後日数の表示
- 次の誕生日までの日数の表示

---

## 使い方

1. `index.html` をブラウザで開きます。
2. 生年月日を入力します。
3. 基準日を入力します。
   - 初期表示時は今日の日付が設定されます。
   - 「今日」ボタンで、生年月日または基準日に今日の日付を設定できます。
4. 「計算」ボタンを押すと、年齢情報が表示されます。
5. 「クリア」ボタンを押すと、生年月日と基準日、計算結果がクリアされます。

---

## 計算内容

| 項目 | 内容 |
| --- | --- |
| 満年齢 | 生年月日から基準日までに迎えた誕生日の回数 |
| 数え年 | 生まれた年を1歳とし、年が変わるごとに1歳加算する年齢 |
| 生後日数 | 生年月日から基準日までの経過日数 |
| 次の誕生日までの日数 | 基準日から次の誕生日相当日までの日数 |
