
# 🧮 計算方法

本ツールでは、入力された「パタポン」「れあポン」「現在レベル」「目標レベル」から、  
必要素材数および必要チャリンを、以下のルールに従って算出します。

---

## 必要素材数の計算方法

### 1) 素材ごとの要求開始レベル

素材は、スロットごとに要求が開始されるレベルが異なります。

| 素材スロット | 要求開始レベル |
| ------------ | -------------- |
| 素材1        | Lv1 から       |
| 素材2        | Lv1 から       |
| 素材3        | Lv3 から       |
| 素材4        | Lv6 から       |

このため、各素材について **要求開始レベル以前のレベル帯は計算対象外**となります。

---

### 2) レベル範囲（差分）の取り扱い

育成コストは「現在レベル `cur` から目標レベル `tgt` まで」の**レベルアップ差分のみ**を対象として計算します。

- `cur = 0, tgt = 5` → Lv1〜Lv5 が対象
- `cur = 5, tgt = 9` → Lv6〜Lv9 が対象

`cur >= tgt` の場合はレベルアップが発生しないため、  
必要素材数・必要チャリンはいずれも **0** になります。

---

### 3) 必要素材数の計算

各素材スロットについて、次の手順で必要素材数を算出します。

1. **素材種類**をパタポンから取得  
   例：とりポン  
   - 素材1 → 野菜  
   - 素材2 → 合金  
   - 素材3 → 木材  
   - 素材4 → 種  

2. **素材ランク**をれあポンから取得（ランク1〜5）

3. 素材スロットごとの **要求開始レベル**を考慮し、  
   「現在レベル〜目標レベル」の範囲から  
   要求開始レベル以前を除外したレベルのみを対象とします。

4. 対象となったレベルごとの要求数を合計します。

---

### 3-1) 実装上の算出方法（累積要求数の差分）

実装では、レベルごとの要求数を 1 つずつ加算するのではなく、  
「レベル1〜N の累積要求数」を閉形式で求め、差分で計算します。

#### レベルごとの要求数

素材ランクを `rank`、レベルを `i` とすると、各レベルの要求数は次の規則に従います。

```math
require(i) = ceil(i / rank)
```

#### 累積要求数

レベル1から `level` までの累積要求数を次のように定義します。

```math
S(rank, level) = Σ_{i=1..level} ceil(i / rank)
```

この累積和は、次の閉形式で計算できます。

```text
q = floor(level / rank)
m = level % rank
S = rank * q * (q + 1) / 2 + m * (q + 1)
```

#### 差分で「cur→tgt」の必要素材数を求める

素材スロットごとの要求開始レベル（素材1/2:Lv1、素材3:Lv3、素材4:Lv6）を考慮し、  
`cur` と `tgt` を「有効レベル」`curEff`, `tgtEff` に補正したうえで、次の差分で求めます。

```math
need = S(rank, tgtEff) - S(rank, curEff)
```

#### プログラムでの実装例

```js
return cumulativeRequired(rank, tgtEff) - cumulativeRequired(rank, curEff);

/**
 * ランク rank とレベル level(0以上) から「レベル1〜levelの累積要求数」を求める。
 * （各レベル i の要求数 = ceil(i / rank) という法則を閉形式で計算）
 *
 * q = floor(level / rank)
 * m = level % rank
 * S = rank * q * (q + 1) / 2 + m * (q + 1)
 */
function cumulativeRequired(rank, level) {
  if (!Number.isInteger(rank) || rank <= 0)
    throw new Error("rank は正の整数である必要があります");
  if (!Number.isInteger(level) || level < 0)
    throw new Error("level は0以上の整数である必要があります");

  const q = Math.floor(level / rank);
  const m = level % rank;
  return (rank * q * (q + 1)) / 2 + m * (q + 1);
}
```

#### 計算例①：素材3（要求開始Lv3）の場合

- 現在レベル：`0`
- 目標レベル：`10`
- 素材ランク：`1`
- 素材スロット：素材3（要求開始Lv = 3）

Lv1・Lv2 は素材3が要求されないため計算対象外となり、  
**Lv3〜Lv10** のみを合計します。

```math
1 + 2 + 3 + 4 + 5 + 6 + 7 + 8 = 36
```

よって、**必要素材数は 36** になります。

#### 計算例②：途中レベルから育成する場合

- 現在レベル：`5`
- 目標レベル：`9`
- 素材ランク：`1`
- 素材スロット：素材1（要求開始Lv = 1）

この場合、対象となるのは **Lv6〜Lv9** です。

```math
6 + 7 + 8 + 9 = 30
```

よって、**必要素材数は 30** になります。

#### 補足：素材が表示されないケースについて

- `tgt < 素材の要求開始レベル` の場合  
  → その素材は一切要求されないため、結果表には表示されません。

---

### 4) 素材名の決定（素材マスタ参照）

出力表に表示する素材名は、素材マスタから

- 素材種類（例：野菜 / 合金 / 木材 / 種 / 肉 など）
- 素材ランク（1〜5）

の組み合わせによって決定されます。

例：

- 素材種類：肉  
- 素材ランク：3  

→ 素材名：「じょじょ肉」

## 必要チャリンの計算方法

### 1) 必要チャリンの計算（倍率適用）

チャリンは、れあポンの **基準チャリン** とパタポンの **チャリン倍率** を用いて算出します。

#### 手順

1. れあポンから **基準チャリン（base）** を取得  
2. レベルアップごとの消費量は  
   「基準チャリン × 上げるレベル」に比例して増加します
3. `cur → tgt` のレベル差分について、次を合計します

   ```math
   (base × (cur+1)) + (base × (cur+2)) + ... + (base × tgt)
   ```

4. 合計値にパタポンの **チャリン倍率（multiplier）** を掛けます

   ```math
    必要チャリン = round( 基準チャリン合計 × multiplier )
    ```

---

#### 計算例：チャリン消費量

- パタポン：とりポン（倍率 2.8）
- れあポン：ババッサ（基準 50）
- 現在レベル：`0`
- 目標レベル：`10`

この場合、

- 基準チャリン合計：`2750`
- 必要チャリン：`2.8 × 2750 = 7700`

となります。
