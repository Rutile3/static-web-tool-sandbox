
# 【パタポン2】育成コスト計算ツール

**【パタポン2】育成コスト計算ツール** は、  
PSP用ゲーム「パタポン2 ドンチャカ♪」における  
**れあポン育成時の素材・チャリン消費量を可視化するための、クライアントサイドWebツール**です。

[👉 ツールを開く（GitHub Pages）](https://Rutile3.github.io/patapon2-growth-cost-calculator/)

---

## 🧩 概要

パタポン2では、れあポンの育成にあたり、

- パタポンの種類
- れあポンの種類
- 現在レベル
- 目標レベル

といった複数の条件によって、  
**必要となる素材の種類・ランク・数量**、および **チャリン消費量** が変動します。

本ツールはそれらをまとめて入力し、

- 必要な素材名
- 各素材の必要数
- 必要チャリン

を **一覧表として即座に算出・表示** することを目的としています。

すべての処理はブラウザ上で完結し、  
**サーバ通信は一切行いません。**

---

## ✨ 主な特徴

- 🐣 **パタポン × れあポンの組み合わせ対応**
  - パタポン種別に応じた素材タイプ・チャリン倍率を自動反映
- 📈 **任意レベル範囲での育成コスト算出**
  - Lv0 → Lv10 だけでなく、途中レベルからの計算も可能
- 🎨 **素材ランク別の色分け表示**
  - ランク2〜5を色分けし、視認性を向上
- 🧱 **素材マスタ・れあポンマスタの分離管理**
  - JSONマスタを用いた明確なデータ構造
- 🪶 **軽量・静的構成**
  - HTML / CSS / JS のみ

---

## 🧰 使い方

1. **ツールを開く**

   → <https://Rutile3.github.io/patapon2-growth-cost-calculator/>

2. **育成条件を入力**
   - パタポン
   - れあポン
   - 現在レベル
   - 目標レベル

3. **「計算」ボタンをクリック**

4. **結果を確認**
   - 素材名（ランク別色分け）
   - 必要素材数
   - 必要チャリン

---

## 🧮 計算方法（概要）

本ツールでは、以下のルールに基づいて育成コストを算出しています。

- 素材はスロットごとに要求開始レベルが異なります
- 育成コストは「現在レベル → 目標レベル」の差分で計算します
- 必要素材数は、対象レベル帯の合計値として算出します
- チャリンは、れあポンの基準値とパタポン倍率を用いて算出します

詳細な計算仕様については、  
👉 [`calculation.md`](calculation.md) を参照してください。
